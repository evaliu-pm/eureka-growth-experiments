# context/目录规则
本目录是Eureka项目上下文的唯一主本。Codex回答Eureka事实时只依据这里和根目录AGENTS.md。

- 每个文件第一行固定为：`最后更新：YYYY-MM-DD｜Owner：姓名｜来源：文件或系统名`。
- 事实、方案、未知分开写；方案写证据编号与状态，未知写"待核"。
- 只写可以放进代码仓库的信息：不放密钥、个人信息、未公开交底、受管制技术数据。
- 改tracking_plan.md、dw_schema.md、metrics.md需智慧芽数据负责人审；改eureka_product.md需产品Owner审。
- 发现文件与系统不一致时，不自行改写事实，开Issue给Owner。
